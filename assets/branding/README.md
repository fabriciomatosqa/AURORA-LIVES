# Marca oficial AURORA

Os derivados desta pasta são produzidos a partir da imagem original **Emblema Triangular Neon Cristalino.png** (1254×1254 RGBA), disponibilizada na biblioteca do proprietário do projeto.

- `apps/desktop/public/aurora-mark.webp`: derivado transparente de 96×96 para a interface.
- `apps/desktop/src-tauri/icons/source.png`: derivado compacto de 64×64 para gerar o conjunto de ícones Tauri usando `npm run icons`.

**Não redesenhar a marca ou substituí-la.** O arquivo original de alta resolução ainda precisa ser incorporado ao repositório quando houver upload binário adequado; não confundir os derivados otimizados com o master em alta definição.
